A job portal for tech companies and developers to connect and find opportunities.

## 🌐 Live Demo

**Experience the platform:** [https://karpardaz-frontend.vercel.app/](https://karpardaz-frontend.vercel.app/)

## ✨ Features

### For Employers
- 📝 **Job Posting**: Create detailed job advertisements with comprehensive requirements
- 👥 **Profile Management**: Manage company profiles and employer details
- 📊 **Application Tracking**: Review and manage job applications
- 🔍 **Candidate Search**: Find qualified job seekers
- 💼 **Interview Management**: Schedule and conduct interviews

### For Job Seekers
- 🔎 **Job Discovery**: Browse and search through available positions
- 📋 **Profile Creation**: Build professional profiles with skills and experience
- 📄 **Resume Upload**: Upload and manage CVs
- 🎯 **Job Applications**: Apply to relevant positions
- 📈 **Recommendations**: Get personalized job recommendations

### Platform Features
- 🌙 **Dark/Light Theme**: Toggle between themes
- 🌍 **RTL Support**: Full Persian/Farsi language support
- 📱 **Responsive Design**: Optimized for all devices
- 🔐 **SSR Authentication**: Secure server-side authentication
- ⚡ **Performance**: Built with Next.js 15 and Turbopack
- 🎨 **Modern UI**: Clean, intuitive interface with Tailwind CSS

## 🛠️ Technology Stack

- **Frontend Framework**: Next.js 15.2.3 with App Router
- **UI Library**: React 19
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS 4
- **HTTP Client**: Axios
- **Validation**: Zod
- **Authentication**: Cookie-based with server-side rendering
- **Development**: Turbopack for fast development
- **Deployment**: Vercel

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm, yarn, pnpm, or bun

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Amir-username/karpardaz-frontend.git
   cd karpardaz-frontend
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. **Start the development server**
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000)
